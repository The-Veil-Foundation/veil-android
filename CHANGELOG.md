# Changelog / История изменений

## 0.3.0 — 2026-11-27

Полное описание релиза на русском и английском: [v0.3.0](docs/releases/v0.3.0.md).
Версия берётся из `VERSION`. Ниже — подробности изменений этой версии.

### Добавлено

- Импорт QR из изображения через системный выбор файла Android, без разрешения камеры
  и доступа ко всей галерее. Результат показывается до подтверждения импорта.
  Поддерживаются инверсия и прозрачный фон; размер файла и число пикселей ограничены.
- Импорт простых групп Mihomo `select` / `url-test` в настройки маршрутизации,
  с обновлением участников и сохранением выбранного узла/пользовательского имени.
  Неподдерживаемые составные группы явно отмечаются, а не меняют семантику молча.
- Маскирование известных секретов и адресов в просмотрщике логов и при копировании;
  оригинальные файлы не изменяются, абсолютная полнота маскирования не гарантируется.
- Перенесены 5 460 записей таблиц macOS для 10 дополнительных языков, добавлены
  выбор языка, определение системной локали и RTL для арабского. Строки без перевода
  остаются по-английски; полный перевод Android-интерфейса ещё не завершён.
- Переименование сервера и подписки в меню действий. Имена сохраняются отдельно
  от данных панели; для серверов используются существующие аннотации.
- Вкладка «Приложение» в просмотрщике логов: события запуска процесса, сохранения
  настроек, запроса подключения и состояния VPN. До 500 событий в памяти, с очисткой.
- Отправка безопасной сводки диагностики: версия, число подписок/серверов и протоколы.
  URL, названия, адреса, ключи, идентификаторы и сырые логи не включаются.
- Предиктивная навигация назад с предпросмотром предыдущего экрана для вкладок,
  вложенных страниц маршрутизации, подписок и дополнительных экранов настроек.
  Навигация подтверждается по завершении жеста; отмена возвращает текущий экран.
- Анимация раскрытия и закрытия поиска серверов.
- Документация ограничений Live Updates и рабочая карта паритета с macOS.

### Изменено

- Верхняя панель без логотипа Veil и надписи «Veil»; названия разделов сохранены.
- Увеличен логотип в кнопках подключения: 32 dp в большой карточке, 36 dp в компактной.
- Убран дублирующий значок слева в компактной карточке; при подключении остаётся индикатор.
- Стрелки скорости заменены иконками загрузки/отдачи; в компактном виде показаны оба значения.
- Настройки оставлены единым прокручиваемым списком. Экспериментальные чипы разделов удалены.
- Сокращено пояснение живого уведомления, чтобы не растягивать строку настройки.
- Запрос Live Updates распространяется на подключение, активный VPN и паузу;
  добавлены короткие состояния `VPN…`, `VPN` и «Пауза».
- Удалены поясняющие комментарии в исходниках и конфигурации; лицензии и рабочие
  директивы сохранены.

### Исправлено

- При смене сервера или ядра VPN активная раздача сохраняет точку доступа,
  мост и пароль прокси. Во время переключения возможен перерыв передачи данных.
  Полное отключение, пауза или ошибка VPN по-прежнему останавливают раздачу.
- Таблицы переводов создаются только для используемых языков; RU/EN не загружают
  дополнительные словари. Неизменившиеся логи не маскируются повторно каждую секунду,
  а обработка новых выполняется вне UI-потока.
- Android TV: отдельная кнопка действий сервера для пульта; прокрутка длинных
  текстов учитывает плотность экрана и не перезапускает анимацию при удержании стрелок.
  Рамка фокуса учитывает отключение анимаций. Кнопка QR из изображения скрывается,
  если на устройстве нет приложения выбора изображений.
- Обновление подписок изолирует одинаковые узлы разных источников, сохраняет ID
  при обновлении ключей и удаляет дубликаты внутри входящего списка. Группы привязываются
  к своему источнику; локальный импорт сохраняет остальные локальные группы.
- При исчезновении выбранного узла после обновления выбирается доступный узел.
  При смене формата подписки удаляются её устаревшие импортированные группы.
- В AIDL-интерфейсе раздачи заданы номера всех методов: устранена ошибка компиляции
  из-за смешивания явных и автоматических номеров; специальный код Shizuku сохранён.
- Создание `LinkAddress` в Shizuku shell-сервисе переведено на reflection:
  публичный Android SDK не предоставляет конструкторов этого класса. Это исправление
  компиляции, а не подтверждение работы экспериментальной раздачи на всех прошивках.
- В VLESS/VMess-конфигах sing-box UUID доступа больше не подменяется внутренним ID записи.
- При обновлении подписки сохраняются ID неизменившихся узлов, а значит, их аннотации
  и ссылки из импортированных групп.
- Расчёт скорости использует монотонное время Android, а не системные часы.
- Убрана интерполяция числовых значений скорости в интерфейсе: показано последнее измерение.
- Выбор APK для обновления учитывает порядок поддерживаемых ABI и универсальный APK.
- Настроена воспроизводимая сборка общего Xray + sing-box AAR для ARMv7, ARM64 и x86_64.
- Добавлен QPACK-адаптер совместимости старого API sing-box с зависимостями Xray.
- Для Go 1.27 включён `http2legacy`: устраняет отсутствующий приватный метод HTTP/2
  и связанные ошибки Android-линковки.
- Добавлена явная Compose-зависимость `androidx.collection` для desktop-компиляции.

### Проверки и ограничения

- Компиляция Android, Kotlin desktop-тесты и тесты QPACK прошли.
- Релизные APK собраны для трёх ABI; ARM64-версия установлена на Samsung SM-S916B
  поверх существующего приложения, без удаления данных.
- Настройки и большая/компактная карточки проверены визуально на телефоне до
  последних изменений поиска и predictive back. Последние изменения собраны и
  установлены, но интерактивная проверка жестов ещё не завершена.
- Now Bar / ColorOS Live Alerts не гарантируются: решение о показе принимает
  прошивка. Отдельная закрытая OEM-интеграция не реализована.
- Полный функциональный паритет с macOS не заявляется; см. [карту переноса](docs/macos-parity.md).

### English summary

Unpublished changes for the current `0.2.0-alpha` working version:

- Server/subscription renaming, bounded session app logs and privacy-safe diagnostics.
- Animated server search and gesture-driven predictive back with previous-screen previews.
- Cleaner header, larger button logos, compact card without a duplicate logo, and
  download/upload icons. Settings retain their original single-list layout.
- Monotonic traffic-speed sampling, ABI-aware APK selection, reproducible combined
  core builds, QPACK compatibility and Go 1.27 `http2legacy` support.
- Android compilation, Kotlin tests, QPACK tests and signed three-ABI release builds passed.
  ARM64 installed on Samsung SM-S916B. Latest predictive gestures still need device testing;
  OEM Live Updates support and full macOS parity are not guaranteed.
