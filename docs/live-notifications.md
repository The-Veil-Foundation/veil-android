# Живое уведомление VPN

Настройки → Живое уведомление. Используется публичный Android Live Updates API
(Android 16 / API 36+), а не плавающее окно поверх других приложений.

- Подключение: `VPN…`; подключено: таймер; пауза: «Пауза».
- Действия: пауза/возобновление и отключение.
- Samsung: отображение через Now Bar возможно, если версия One UI разрешает
  сторонние Live Updates. Наличие Android 16 само по себе этого не гарантирует.
- OPPO/ColorOS: системный Live Alerts зависит от поддержки публичного API,
  региона, версии оболочки и допуска приложения. Отдельная закрытая OEM-
  интеграция не реализована; обход списков разрешённых приложений не используется.
- На старых или несовместимых прошивках остаётся обычное foreground-уведомление.
- Дополнительно включите уведомления и разрешение Live Updates в настройках
  Android. Оболочка может отдельно ограничивать фоновые процессы.
- VPN может не соответствовать критериям продвижения уведомлений конкретного
  производителя. Приложение запрашивает показ, окончательное решение за системой.

Проверка: подключение → таймер → пауза → возобновление → отключение;
выключение функции; запрет уведомлений; закрытый экран; обычное уведомление
на API ниже 36. Показ в ColorOS и Now Bar на реальных устройствах пока не проверен.

Документация API: https://developer.android.com/develop/ui/views/notifications/live-update
