# Паритет с macOS

Срез исходников: `veil-macos` commit
`42ce7684b50145dce18259e3843bcac900a3113b`.
Локальная копия: `../veil-macos`. Это рабочая карта, не заявление о полном паритете.

## Уже есть в Android; нужна проверка соответствия поведения

- Xray и sing-box, импорт ссылок и подписок, QR и передача на TV.
- Маршрутизация, DNS, группы, community-списки и загрузка geo-баз:
  `RoutingScreen.kt`, `RoutingEditors.kt`, `XrayConfig.kt`, `SingboxConfig.kt`.
- Проверка узлов, переключение, автообновление подписок, обновление APK.
- Аннотации узлов и имена источников; добавлено меню переименования.
- Добавлена отправка безопасной агрегированной сводки диагностики. Это не
  полный аналог отчёта macOS: сырые логи и конфигурации намеренно исключены.
- Импортируются простые группы Mihomo `select`/`url-test`; вложенные группы,
  провайдеры, фильтры и встроенные участники `DIRECT`/`REJECT` явно пропускаются.
- Просмотр и копирование логов маскируют известные секреты/адреса; файлы остаются
  исходными. Полное обезличивание произвольного текста не гарантируется.
- Перенесены 5 460 переводов macOS для 10 дополнительных языков. Выбор языка
  и арабское RTL реализованы; Android-специфичные строки требуют доперевода.
- Добавлен выбор QR-изображения с ограничением размера, поддержкой инверсии и
  прозрачности; декодированный текст требует подтверждения перед импортом.

## Платформенные отличия

- launchd, sudo/helper, Keychain, menu bar и SMAppService не копируются.
  Аналоги: VpnService, Android Keystore, уведомления/плитка, настройки Android.
- Без root обычное приложение не может установить глобальный системный
  SOCKS-прокси для всех приложений. Основной режим Android — VpnService/TUN;
  отдельный локальный прокси требует самостоятельного проектирования.
- Per-process правила macOS нельзя обещать как прямой перенос на Android:
  доступная альтернатива — маршрутизация приложений через VpnService.
