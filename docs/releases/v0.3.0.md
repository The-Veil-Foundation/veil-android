# Veil 0.3.0

## Русский

### Новое
- Импорт QR из изображения: системный выбор файла, поддержка инверсии и прозрачного фона, подтверждение перед добавлением.
- Импорт простых групп Mihomo `select` и `url-test`, обновление участников с сохранением пользовательского имени и выбора.
- Экспериментальная раздача VPN через Shizuku (Android 13+) и HTTP/SOCKS5-прокси с авторизацией.
- 10 дополнительных языков из macOS, RTL для арабского. Специфичные для Android строки пока переведены не полностью.
- Журнал событий приложения, маскирование известных секретов в просмотрщике логов и агрегированная диагностика.
- Переименование узлов и источников, улучшения поиска, переходов и уведомлений VPN.

### Исправления и оптимизации
- При смене сервера или ядра активная раздача сохраняет точку доступа и пароль прокси. Во время переключения передача данных может прерываться.
- Обновление подписок сохраняет ID неизменившихся узлов, разделяет одинаковые узлы разных источников и корректирует импортированные группы.
- Исправлена передача UUID доступа в конфигурации VLESS/VMess для sing-box.
- Android TV: кнопка действий сервера для пульта, прокрутка длинного текста, вход фокуса в настройки, фон экрана и подсветка.
- Таблицы переводов загружаются по необходимости; неизменившиеся логи не маскируются повторно, маскирование вынесено из UI-потока.
- Обновлены сборка объединённого ядра Xray/sing-box и совместимость Go; APK доступны для ARMv7, ARM64, x86_64 и в универсальном варианте.

### Установка и ограничения
- Для большинства телефонов выбирайте `arm64-v8a`; для 32-битных приставок — `armeabi-v7a`. Универсальный APK содержит все три архитектуры и занимает больше места.
- Обновляйте поверх установленного приложения с той же подписью, чтобы сохранить данные.
- Раздача Shizuku экспериментальная и зависит от прошивки. Сохранение точки доступа при переключении VPN ещё требует проверки на устройстве; отключение, пауза или ошибка VPN останавливают раздачу.
- Вложенные и provider-based группы Mihomo ещё не поддерживаются. Маскирование логов не изменяет исходные файлы и не гарантирует удаления всех секретов.
- Компиляция Android и desktop-тесты прошли. Полная проверка TV-навигации и всех сетевых сценариев на устройствах не завершена.

## English

### Added
- QR import from images using the system picker, with inverted/transparent QR support and confirmation before importing.
- Simple Mihomo `select` and `url-test` group import, refreshing members while preserving custom names and selection.
- Experimental VPN sharing through Shizuku (Android 13+) and an authenticated HTTP/SOCKS5 proxy.
- Ten additional macOS translation tables and Arabic RTL. Android-specific translations remain incomplete.
- In-app event log, masking of known secrets in the log viewer, and aggregate diagnostics.
- Node/source renaming and improvements to search, navigation transitions and VPN notifications.

### Fixes and performance
- Active sharing retains the hotspot and proxy credentials when switching VPN servers or cores. Traffic may briefly pause during the switch.
- Subscription refresh preserves unchanged node IDs, isolates identical nodes from different sources and updates imported groups.
- Fixed VLESS/VMess access UUIDs in sing-box configurations.
- Android TV: remote-friendly server actions, long-text scrolling, settings focus entry, screen background and focus highlighting.
- Translation dictionaries load on demand. Unchanged logs skip repeated masking, and masking runs off the UI thread.
- Updated combined Xray/sing-box builds and Go compatibility; ARMv7, ARM64, x86_64 and universal APKs are provided.

### Installation and limitations
- Choose `arm64-v8a` for most phones or `armeabi-v7a` for 32-bit TV boxes. The larger universal APK includes all three architectures.
- Install over the existing app with the same signing certificate to retain data.
- Shizuku sharing is experimental and firmware-dependent. Hotspot retention during VPN switching still needs hardware validation; VPN disconnect, pause or failure stops sharing.
- Nested and provider-based Mihomo groups are not supported yet. Log masking leaves original files unchanged and cannot guarantee removal of every secret.
- Android compilation and desktop tests passed. Full TV-navigation and network-scenario validation on hardware is still pending.
